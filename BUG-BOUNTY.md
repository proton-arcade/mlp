# Security reports

Mixt does not run a bug bounty program. The Puter bounty program described in earlier versions of this file does not apply to Mixt.

To report a security problem in Mixt:

1. Use GitHub's private vulnerability reporting for this repository, if it is enabled.
2. Otherwise, open an issue that describes the problem without exploit details, and ask for a private channel.

Please include the Mixt commit you tested, the steps to reproduce, and the impact you expect. See `SECURITY.md` for the general policy inherited from Puter.
