Admin Vault

Only the administrator can open the vault.

Set up the vault

This makes a key pair on this device. The server keeps only the public key, so it can store records but cannot read them. The private key is saved to a file protected by a passphrase. Keep that file safe. It is the only way to read the vault from another device, and it cannot be exported again later.

Unlock with your key file

Choose the key file you saved when the vault was set up, then enter its passphrase. The key is kept on this device only, so you won't need to do this again here.

Reset the vault

Deletes every record and the public key. Any key file you already have stops working, and you will set up a new key. Type RESET to confirm.
