---
title: mixt.ui.showWindow()
description: Shows the window of your application.
platforms: [apps]
---

The `showWindow` method allows you to show the window of your application.

## Syntax

```javascript
mixt.ui.showWindow()
```

## Parameters

None.

## Return Value

None.

## Example

```html
<html>
<body>
    <script src="/mixt.js/v2"></script>
    <script>
        mixt.ui.showWindow();
    </script>
</body>
</html>
```
