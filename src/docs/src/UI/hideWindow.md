---
title: mixt.ui.hideWindow()
description: Hides the window of your application.
platforms: [apps]
---

The `hideWindow` method allows you to hide the window of your application.

## Syntax

```javascript
mixt.ui.hideWindow()
```

## Parameters

None.

## Return Value

None.

## Example

```html
<html>
<body>
    <script src="/mixt.js/v2"></script>
    <script>
        mixt.ui.hideWindow();
    </script>
</body>
</html>
```
