The Utilities API provides helpful utility functions and properties that make development easier and more efficient. These utilities help with common tasks and provide access to important system information.

## Available Functions

- **[`mixt.print()`](/Utils/print/)** - Print text to console or output
- **[`mixt.randName()`](/Utils/randName/)** - Generate random names
- **[`mixt.appID`](/Utils/appID/)** - Get the current application ID
- **[`mixt.env`](/Utils/env/)** - Access environment variables
