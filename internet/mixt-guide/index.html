Mixt Guide

The desktop

The bottom panel holds the menu button and the open windows. The Files app keeps your documents in your home folder.

The browser

Use the back and forward buttons to move between pages, and the home button to return to MPLmit. Only pages stored in the internet folder can be opened.

Adding a page

Each page is a folder inside the internet folder of the Mixt program, with an index.html file. Restart Mixt after adding or removing a folder.
